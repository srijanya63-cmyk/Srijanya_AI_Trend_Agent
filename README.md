# AI News Brief Agent

A personalized AI-powered news agent that delivers 
customized content briefs to subscribers via email — 
no app installation required!

## How It Works
1. Fetches live news from RSS Feed automatically
2. Sends to Google Gemini AI for processing
3. Generates personalized content brief per subscriber
4. Emails each subscriber their customized update

## What Makes It Different
Other apps tell you WHAT happened.
This AI Agent tells you WHAT TO DO with it.

Every subscriber gets:
-  Content Idea based on trending news
-  Ready-made Hook
-  Personalized Angle based on their interests

## Tech Stack
- Make.com (Automation Platform)
- Google Gemini AI (Content Generation)
- RSS Feed — Times of India / BBC India (News Source)
- Google Sheets (Subscriber Database)
- Gmail API (Email Delivery)
- Google Forms (Subscriber Collection)
